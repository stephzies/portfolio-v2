# Stephanie OCampo | Portfolio 2.0

A static product design portfolio. The homepage is `index.html`; the case studies are `startzie/index.html`, `trip-kit/index.html`, and `xrayux/index.html`. All pages share `styles.css`. The case-study pages document the design work; they do not host the products.

For local review, run `python3 -m http.server 8000` from this directory and visit `http://localhost:8000`. For GitHub Pages, publish the repository root from its main branch. All links use relative paths so the site also works under a project subpath or a custom domain.
